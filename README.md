# 📈 Stock Price Prediction (Apple Inc.)

## Objective
Predict the next day’s closing stock price using Open, High, Low, and Volume as features.

## Dataset
- Source: yfinance API
- Stock: AAPL (Apple Inc.)
- Time Range: 2020–2024

## Methods
- Linear Regression using scikit-learn
- Visualized predicted vs actual prices

## Results
- RMSE and R² score reported
- Graph of predicted vs actual closing prices
